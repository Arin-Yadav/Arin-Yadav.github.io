# Personal Portfolio Website

## Live Preview
Visit the deployed site: [Arin-Yadav.github.io](https://Arin-Yadav.github.io)

A responsive **portfolio website** built using **HTML, CSS, and JavaScript**.  
This project serves as a personal showcase of skills, projects, and career journey, designed with a clean, recruiter‑friendly layout and modern UI polish.

---

## Features
- **Home Section**
  - Introduction with name, role, and tagline.
  - Hero layout with call‑to‑action buttons.

- **About Section**
  - Concise biography highlighting education and professional goals.

- **Skills Section**
  - Grid layout of technical skills with icons and labels.
  - Responsive design ensures proper alignment across devices.

- **Projects Section**
  - Card‑based layout with project images, descriptions, and links.
  - Hover effects and transitions for modern polish.

- **Education Section**
  - Timeline or structured list of academic background.

- **Contact Section**
  - Contact form with JavaScript validation.
  - Social media links/icons for networking.

---

## Tech Stack
- **HTML**: Semantic structure for accessibility and SEO.  
- **CSS**: Responsive layouts using Flexbox and Grid, hover effects, gradient text, and animations.  
- **JavaScript**: Form validation, interactive elements, and smooth navigation.  

---

## Responsiveness & UI/UX
- Mobile‑first design with adaptive layouts.  
- Sticky/flex‑based navigation for easy access.  
- Smooth transitions and hover states for interactivity.  
- Consistent card styling across sections for professional polish.  

---

## Professional Value
This portfolio demonstrates:

# Arin-Yadav.github.io

A simple static website hosted using **GitHub Pages** — free, fast, and perfect for showcasing personal projects. This task demonstrates how to deploy a front-end website directly from a public GitHub repository.

## Objective
- Host a static website using GitHub Pages
- Make the site publicly accessible via a custom GitHub Pages URL
- Practice version control and deployment using Git CLI or GitHub Desktop

## Tools & Technologies

- **GitHub Account** – Repository hosting and Pages deployment
- **Git CLI / GitHub Desktop** – Version control and publishing
- **HTML, CSS, JS** – Static website files
- **Chrome Browser** – Testing and preview

## Deployment Steps

1. Create a new public repository named `Arin-Yadav.github.io`
2. Add your static website files (`index.html`, `style.css`, etc.)
3. Commit and push changes to the `main` branch
4. Go to **Settings > Pages** and select the `main` branch as the source

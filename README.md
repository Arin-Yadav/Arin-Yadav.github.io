# Personal Portfolio Website

## Live Preview
Visit the deployed site: [Arin-Yadav.github.io](https://Arin-Yadav.github.io)

A responsive **portfolio website** built using **HTML, CSS, and JavaScript**.  
This project serves as a personal showcase of skills, projects, and career journey, designed with a clean, recruiter‑friendly layout and modern UI polish.

---

## Tech Stack
- **HTML**: Semantic structure for accessibility and SEO.  
- **CSS**: Responsive layouts using Flexbox and Grid, hover effects, gradient text, and animations.  
- **JavaScript**: Form validation, interactive elements, and smooth navigation.
